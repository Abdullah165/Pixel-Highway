# Pixel Highway
Welcome to Pixel Highway! Test your reflexes by dodging cars and obstacles in an endless high-speed challenge.

Your goal is simple: survive as long as you can to set a new high score. One crash, and it's game over!

This game was made with C++ and the wonderful raylib library.
